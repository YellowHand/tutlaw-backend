# API: karty (administrator)

[← Przegląd API](README.md) · [Spis treści](../README.md)

Wszystkie endpointy tej grupy wymagają roli **ADMIN** (zwykły użytkownik dostaje `403`). Karty uczniom dostarczają
wyłącznie [kolejki nauki](05-nauka.md), które nie zawierają poprawnych odpowiedzi; tutaj odpowiedzi są widoczne,
dlatego odczyt jest zastrzeżony.

Jak karta jest zbudowana w bazie i jakie ma ograniczenia: [02. Baza danych](../02-baza-danych.md#cards--pytania-testowe-i-fiszki).

## Obiekt karty (`CardResponse`)

```json
{
  "id": 101,
  "chapterId": null,
  "sourceId": 31,
  "type": "DEFINITION",
  "front": "Czy czyn zabroniony popełniony w stanie wyższej konieczności jest przestępstwem?",
  "back": null,
  "pageNumber": null,
  "verbatimQuote": false,
  "tagNames": ["kontratyp"],
  "optionA": "Tak, zawsze",
  "optionB": "Nie, jeżeli dobro poświęcone nie przedstawia wartości oczywiście większej od dobra ratowanego",
  "optionC": "Tak, ale sąd odstępuje od wymierzenia kary",
  "correctOption": "B",
  "explanation": "Stan wyższej konieczności jest kontratypem (art. 26 k.k.).",
  "legalBasis": "art. 26 § 1 k.k.",
  "validAsOf": "2026-01-01",
  "linkedTestCardId": null,
  "origin": "NOTARY",
  "examYear": 2024,
  "hidden": false,
  "autoGenerated": false
}
```

Dla fiszki `correctOption`, `optionA/B/C` są `null`, a `back` zawiera odwrót. `autoGenerated: true` oznacza fiszkę
utworzoną automatycznie z pytania (wyzwalacz w bazie).

## `GET /api/chapters/{chapterId}/cards` i `GET /api/sources/{sourceId}/cards`

Karty rozdziału / źródła w kolejności `id`, stronicowane.

| Parametr | Opis |
|----------|------|
| `page` | Numer strony od 0 (domyślnie 0) |
| `size` | Rozmiar strony 1–200 (domyślnie 50) |

Odpowiedź: `{ "items": [ CardResponse... ], "page": 0, "size": 50, "totalElements": 137, "totalPages": 3 }`.

W wynikach są także karty **ukryte** i fiszki automatyczne (administrator widzi wszystko).

## `POST /api/cards` — dodanie jednej karty

**Ciało żądania (`CardRequest`)**

| Pole | Wymagane | Opis |
|------|----------|------|
| `sourceId` | tak | Źródło karty |
| `type` | tak | `DEFINITION`, `PAREMIA`, `COMPARISON` albo `CLOZE` |
| `front` | tak | Treść pytania / przód fiszki |
| `chapterId` | zależy | Rozdział; **wymagany** dla źródła typu `TEXTBOOK`. Musi należeć do tego samego źródła |
| `back` | dla fiszki | Odwrót fiszki. Dla pytania testowego może być pusty |
| `optionA`, `optionB`, `optionC`, `correctOption` | dla pytania | Pytanie testowe: komplet trzech różnych odpowiedzi i wskazanie poprawnej (`A`/`B`/`C`) |
| `explanation` | nie | Wyjaśnienie pokazywane po odpowiedzi |
| `legalBasis` | nie | Podstawa prawna, do 500 znaków |
| `validAsOf` | nie | Stan prawny na dzień (`"2026-01-01"`) |
| `pageNumber` | nie | Numer strony, nieujemny |
| `verbatimQuote` | nie | Czy treść to dosłowny cytat (domyślnie `false`) |
| `tagIds` | nie | Lista numerów tagów |
| `linkedTestCardId` | nie | **Tylko fiszka**: pytanie testowe, z którym fiszka jest powiązana |
| `origin` | nie | Pochodzenie; puste = `AUTHORED` |
| `examYear` | zależy | Rok egzaminu: **wymagany** dla pochodzeń innych niż `AUTHORED`, **zabroniony** dla `AUTHORED`; 1990–2100 |

**Reguły treści** (klasa `CardContentRules`; błędy łączone w jeden komunikat po polsku):

- `front` nie może być pusty;
- karta bez żadnego pola testowego jest fiszką i musi mieć `back`;
- jeśli jest którekolwiek pole testowe, muszą być **wszystkie trzy odpowiedzi** różniące się od siebie (porównanie bez
  względu na wielkość liter, nadmiarowe spacje i końcową interpunkcję) oraz wskazana `correctOption`;
- pytanie testowe nie może mieć `linkedTestCardId`; fiszkę można powiązać tylko z kartą, która jest pytaniem testowym;
- karta z podręcznika musi mieć rozdział;
- podstawa prawna do 500 znaków; rok egzaminu zgodny z pochodzeniem.

**Odpowiedź:** `200` i obiekt karty. **Błędy:** `400` (naruszona reguła treści), `404` (nie ma źródła, rozdziału,
tagu albo pytania do powiązania), `409` („Taka karta już istnieje w tym źródle”), `403`.

**Duplikaty:** dwie karty w tym samym źródle są duplikatem, gdy mają ten sam przód i tę samą odpowiedź (dla pytań:
komplet opcji i poprawną odpowiedź). Do klucza wchodzi też **pochodzenie i rok** (to samo pytanie z innego roku albo z
innej aplikacji jest osobnym pytaniem). Automatyczne fiszki nie biorą udziału w wykrywaniu duplikatów.

Przy dodawaniu pytania testowego wyzwalacz w bazie **sam tworzy jego fiszkę** (widoczną dla uczniów dopiero po pewnym
błędzie albo ręcznym dodaniu).

## `POST /api/cards/bulk` — import zbiorczy

**Ciało żądania:** `{ "cards": [ CardRequest, CardRequest, ... ] }`. Pusta lista daje `400` („Lista kart jest pusta”).

Poprawne i niepowtarzające się wiersze zapisują się **w jednej transakcji**; wiersze błędne i zduplikowane są pomijane
i opisane w wyniku. Wiersze są numerowane od 1.

```json
{
  "created": 48,
  "duplicates": 2,
  "errors": [
    "Wiersz 7: Odpowiedzi A, B i C muszą się od siebie różnić.",
    "Wiersz 19: Nie znaleziono źródła o id 999"
  ]
}
```

Duplikaty liczą się względem kart już zapisanych w źródle **i** względem wcześniejszych wierszy tego samego importu.

## `PUT /api/cards/{id}/hidden` — ukrycie / przywrócenie karty

```json
{ "hidden": true }
```

Ukryta karta znika **wszystkim użytkownikom** (testy, fiszki, liczniki, losowanie egzaminu). Historia odpowiedzi zostaje.
Ukrycie pytania ukrywa też jego automatyczną fiszkę, a przywrócenie ją odkrywa (robi to wyzwalacz w bazie).
Odpowiedź `200`: karta po zmianie. Błąd `404`, gdy nie ma karty.
